# Decision: frankx.ai homepage

Director, 2026-10-20.

**Chosen: B, "The studio window"**, carrying A's blueprint trace as its content.

- B is the only direction that satisfies the brand's first rule ("start with a real person, artifact, observation or working scene", DESIGN.md §1) with both a scene and an artifact.
- It beats the bar (Simon Willison on proof density) the same way A does, and adds the place, which A lacks.
- A stays as the fallback if a future render fails inspection: same copy, same trace, no image.

**Rejected:**

- **A, the workbench:** correct but reads as a developer tool; a non-coding founder may leave before the trace means anything.
- **C, the field notebook:** the strongest phone experience, but its proof depends on a publishing cadence the site does not show today; a stale date is worse than none. Worth revisiting for the `/notes` route.

**GPU decision (gpu-artist):** no WebGL. CSS backdrop glass over the generated image carries the "liquid glass" job; a shader would add bundle and battery cost without a stated job the CSS cannot do. One pointer-following specular highlight, on fine pointers only.

**Human gates before this reaches frankx.ai:** the homepage is a protected surface and the change removes more than half of the current page. Frank approves the direction on the canvas; the build then goes to a draft PR.
