# skill-builder

> Card for the **Skills that ship with their evals** pack. Generated by `scripts/eval-card.mjs`; do not edit by hand.

## What it does

Writes and reviews Agent Skills (SKILL.md) so they load, trigger at the right time and stay safe to share.

## When it triggers

Routing text (the only part an agent sees before loading the skill): "Writes Agent Skills. Use when creating, reviewing or fixing a SKILL.md: frontmatter, a description that triggers, progressive disclosure, folder layout."

- "use when" cue starts at character 21. Survives Codex trimming descriptions on a large install (about 100 characters once roughly 80 or more skills are installed; full text on small installs).
- Trigger test: fires on the review tasks below; must stay quiet on an adjacent task such as "Summarise the difference between a git merge and a git rebase in three bullet points".
- Context cost: listed in every session; full body loads only when it fires (body under 500 lines).

## What the eval checks

| Case | What it measures | Graders |
|---|---|---|
| clean | Precision. A well-formed skill folder; the review must not invent defects. | 2 |
| no-trigger | Should NOT trigger skill-builder: an adjacent but different task. | 1 |
| seeded-defects | Recall. An Agent Skill folder with eight seeded authoring defects against the Agent Skills specification. | 9 |
| write-skill | Outcome. Author a SKILL.md for a described workflow; graded on the Agent Skills spec and on routing text that survives Codex's ~100-character description window. | 5 |

8 planted defects in the recall case. The answer key and the graders are held out: never shown to the model, and not published. Every case runs twice: with the skill and with no skill (baseline), same model and prompt.

## Install

Release candidate: until this pack is merged to `main`, pin the branch (`#` for Claude Code, `@` for Codex).

```bash
# Claude Code (2.1.310 tested)
claude plugin marketplace add frankxai/claude-skills-library#agent/hyperagent/eval-pack-rc1
claude plugin install skills-with-evals@claude-skills-library
# Codex (codex-cli 0.164.0 tested)
codex plugin marketplace add frankxai/claude-skills-library@agent/hyperagent/eval-pack-rc1
codex plugin add skills-with-evals@claude-skills-library
```

After merge, drop the `#…` / `@…` suffix. Already added this marketplace from `main`? Remove it first (`claude plugin marketplace remove claude-skills-library`, `codex plugin marketplace remove claude-skills-library`): both runtimes refuse a second source under the same name.
