# nextjs-expert

> Card for the **Skills that ship with their evals** pack. Generated by `scripts/eval-card.mjs`; do not edit by hand.

## What it does

Reviews and builds Next.js 16 App Router code, including the version-specific changes that compile fine and break in production.

## When it triggers

Routing text (the only part an agent sees before loading the skill): "Comprehensive Next.js expertise across App Router, server/client boundaries, data and caching patterns, and production operations. Use when building, debugging, or optimizing a Next.js app, deciding server vs client components, or resolving App Router gotchas."

- "use when" cue starts at character 131. Outside the ~100 characters Codex shows in its skill list, so Codex has to guess from the first sentence.
- Trigger test: fires on the review tasks below; must stay quiet on an adjacent task such as "Write an Express.js middleware that logs each request's method, path and duration in milliseconds".
- Context cost: listed in every session; full body loads only when it fires (body is 707 lines (guide: under 500)).

## What the eval checks

| Case | What it measures | Graders |
|---|---|---|
| clean | Precision. The corrected version of the same route; the review must not invent defects. | 2 |
| no-trigger | Should NOT trigger nextjs-expert: an adjacent but different task. | 1 |
| seeded-defects | Recall. A Next.js 16 blog route about to ship, with nine seeded production and security defects (five are Next.js 16 specific). | 10 |

9 planted defects in the recall case (answer key never shown to the model). Every case runs twice: with the skill and with no skill (baseline), same model and prompt.
