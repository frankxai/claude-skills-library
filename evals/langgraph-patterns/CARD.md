# langgraph-patterns

> Card for the **Skills that ship with their evals** pack. Generated by `scripts/eval-card.mjs`; do not edit by hand.

## What it does

Builds and debugs LangGraph agents: state reducers, routing, tool binding, checkpointing and human-in-the-loop interrupts.

## When it triggers

Routing text (the only part an agent sees before loading the skill): "Production-grade agentic workflows with LangGraph — graph orchestration, state machines, human-in-the-loop, and advanced control flow. Use when building or debugging a LangGraph app, modeling agent state, or adding checkpoints and human approval steps."

- "use when" cue starts at character 135. Outside the ~100 characters Codex shows in its skill list, so Codex has to guess from the first sentence.
- Trigger test: fires on the review tasks below; must stay quiet on an adjacent task such as "Write a Python function that retries an HTTP GET with exponential backoff (max 5 attempts) using the requests library".
- Context cost: listed in every session; full body loads only when it fires (body under 500 lines).

## What the eval checks

| Case | What it measures | Graders |
|---|---|---|
| clean | Precision. A correct version of the same agent; the review must not invent runtime bugs. | 2 |
| no-trigger | Should NOT trigger langgraph-patterns: an adjacent but different task. | 1 |
| seeded-defects | Recall. A LangGraph expense-approval agent with seven seeded defects in state, routing, tools and human-in-the-loop. | 8 |

7 planted defects in the recall case (answer key never shown to the model). Every case runs twice: with the skill and with no skill (baseline), same model and prompt.
