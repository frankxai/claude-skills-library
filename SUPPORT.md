# Get help

| Need | Best place |
| --- | --- |
| How to use a skill | [Q&A discussions](https://github.com/frankxai/claude-skills-library/discussions/categories/q-a) |
| A working example others can learn from | [Show and tell](https://github.com/frankxai/claude-skills-library/discussions/categories/show-and-tell) |
| A reproducible bug | [Bug report](https://github.com/frankxai/claude-skills-library/issues/new/choose) |
| A skill idea | [Ideas discussions](https://github.com/frankxai/claude-skills-library/discussions/categories/ideas) or a [skill request](https://github.com/frankxai/claude-skills-library/issues/new/choose) if the scope is clear |
| A security vulnerability | [Private security report](SECURITY.md) |
| A conduct concern | [Code of conduct reporting](CODE_OF_CONDUCT.md) |

This is a community maintained project. Include the skill name, agent, version if known, and a minimal example when asking for help. Remove secrets and personal data before posting.
