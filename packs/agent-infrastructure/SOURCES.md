# Sources & reconciliation

Every skill in this pack is **estate-native**: authored in Frank's repos in the
claude-flow / agentic-flow idiom, not vendored verbatim from a third-party
repository. The canonical copy of each lives in this library's `free-skills/`
tree — that is the pack's only upstream, `install.sh` reads it directly, and
the pack carries no second copy that could rot against it. The skills reference
the open-source [claude-flow](https://github.com/ruvnet/claude-flow) and
agentic-flow CLIs as tooling; no directory here is a copy of those repos.

## How canon was decided, per skill

found these skills in 3–5 repos each, in up to 4 versions under one name. Every
version was diffed before choosing canon. Two mechanical mutations account for
most of the apparent divergence and were discounted first: `arcanea`'s copies
differ only by CRLF line endings, and `arcanea-ai-app`'s only by an injected
`version: "1.0.0"` frontmatter line.

## The known deliberate fork — do not flatten it

`FrankX` and `frankx.ai-vercel-website` carry a **different skill under the
name `swarm-orchestration`**: "Swarm Orchestration, Memory, & Model Routing"
v14.0.0 — a SIP-flavored framework covering topology selection, an AgentDB
SQLite schema at `.acos/agentdb.db`, a 3-tier model-routing table, and a
structured cognitive-tag protocol. That is a legitimate repo-specific
customization, not rot, and this pack does not erase it: `install.sh` sets a
diverged copy aside to `.claude/skills/.replaced/` and names it loudly instead
of overwriting in place.

**Flagged for Frank, not decided here:**

1. The fork should get its **own name** in those two repos (e.g.
   `sip-swarm-routing`) so it and the canonical skill can coexist — same-name
   coexistence is exactly the drift an agent trips over. Renaming inside those
   repos is a consumer-side step, out of scope for this library change.
2. The fork's Tier table quotes **Claude 3.5 Sonnet, GPT-4o, o1, o3-mini and
   DeepSeek-R1** as current routing targets — the same class of stale model
   facts corrected in this library's `model-routing` skill on 2026-08-28. Its
   AgentDB section also overlaps `reasoningbank-agentdb`. Worth reconciling
   when it is renamed.

## Considered and excluded

- **`opus-extended-thinking`** — drifted (estate copies still teach the
  Opus 4.5 / `budget_tokens` API of late 2025), and the corrected v2.1.0
  already lives in `free-skills/`. Excluded because it is a model-API usage
  skill, not agent infrastructure — it does not install-with or cross-reference
  this set. Consumers pick it up through the catalog channel.
- **`github-code-review` / `-multi-repo` / `-project-management` /
  `-release-management`** — drifted, already canonical in `free-skills/`, and
  the divergence is mechanical-only. They group by usage with repo workflow,
  not swarm runtime; a candidate second pack.
- **The Anthropic document set** (`xlsx`, `pptx`, `pdf`, `docx`,
  `doc-coauthoring`) — the measured "3 versions" collapse to **zero real
  variants** after discounting CRLF and version-stamp noise; four of five are
  already byte-identical to `free-skills/anthropic/`, aux files included.
  Nothing to reconcile; a future pack is pure fan-out.
