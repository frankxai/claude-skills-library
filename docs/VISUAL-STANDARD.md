# Visual standard

The public catalog should look like the repositories people actually star: one sentence, one proof, one install path. Not a poster.

## What the top lists do

`sindresorhus/awesome`, `public-apis`, and `free-programming-books` win on scan speed. The first screen answers what it is, who it is for, and how to start. Badges are few and factual. Categories are tables, not card walls.

`obra/superpowers` and `hesreallyhim/awesome-claude-code` win on a sharper claim: a skill is not a prompt dump. It is a tested workflow with a trigger.

## Mark

[`.github/assets/mark.svg`](../.github/assets/mark.svg) is the square mark. Deep field `#0B1020`, star `#F4F7FF`, accent ring `#7C9CFF`. Use it at 128 and 512. Do not recolor it per skill. The existing hero banner stays the wide social image.

## Language

- Lead with the count and the install command.
- Say what a skill is not: not a chat prompt, not an always-on tool schema.
- Name the sibling repos. This catalog is the storefront. `frankxai/skills` and `frankxai/creator-skills` are the curated lanes. Starlight is the substrate.
- No invented quotations, no placeholder metrics, no gradient headlines.

## Done when

A stranger can install one skill in under a minute, see the category table, and find the authoring spec without leaving the README.
