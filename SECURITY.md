# Security policy

Agent skills can influence tool use and expose data. Review a skill and its permissions before installing or running it in a sensitive environment.

## Report a vulnerability

Use this repository's **Security → Report a vulnerability** option to send a [private vulnerability report](https://github.com/frankxai/claude-skills-library/security). Private reporting is enabled for this repository. Include the affected skill or file, impact, and steps to reproduce without submitting live credentials or other people's data.

Do not publish exploit details in an issue, pull request, or discussion while a fix is being coordinated. The maintainer will assess the report, discuss a fix privately, and publish an advisory when appropriate. No response or fix deadline is promised.

For ordinary bugs, use the [issue templates](https://github.com/frankxai/claude-skills-library/issues/new/choose).
