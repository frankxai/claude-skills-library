# Movement Brief: template with field notes

Produce this as one document. Keep the headings; fill every block; write `[OPEN]` where a
fact is unknown rather than guessing. Tag measured facts with the method and date.

---

# Movement Brief: [brand or product]

Author, date, revision. Sources read (with dates).

## 1. Market reality

- **Sophistication stage** (1 to 5) and the evidence (which claims three or more competitors
  already make).
- **Awareness map**: estimated share of the traffic you will meet at each stage, and where it
  comes from.
- **Competitor-language table**: five closest alternatives (include "do nothing" and the
  general-purpose AI assistant). Columns: headline claim, named mechanism, identity offered,
  price, source and date.
- **Swipe log**: ten to twenty verbatim buyer phrases for the pain and the dream, with source.

## 2. Buyer and bar

- **Best-fit customer**: who already loves this, in a sentence they would recognise.
- **Alternatives**: what they honestly do today if this did not exist.
- **Three references to beat**, each on one named dimension, each opened this week.

## 3. Movement core

- **Leader**: name, backstory in three beats, the epiphany bridge (the moment the new
  opportunity became visible), two flaws kept in, the polarity (what they are against).
- **Cause**: one-line future state. Slogan members can say. Identity label.
- **New opportunity**: the new vehicle, the old vehicle it replaces, why the old one cannot
  get there.
- **Rituals**: one recurring format, one piece of shared vocabulary, one visible badge.
- **Proof plan**: what receipts, results and mechanism will sit inside the pages, one scroll
  below the identity headline.

## 4. Offer

- **Value equation worked**: dream outcome, likelihood (and its proof), time to first result,
  effort removed.
- **Stack**: components, each mapped to the objection it answers.
- **Price hypothesis** and the evidence state (`none yet`, `waitlist bands`, `paid orders`).
- **Risk reversal**, honest, with the exact terms.

## 5. Ladder

| Rung | Product | Gift (slice of it) | Shape | Gate state | Till |
|---|---|---|---|---|---|
| Free | | | | | |
| Entry | | | | | |
| Core | | | | | |
| Continuity | | | | | |
| Premium | | | | | |

Gate state is `waitlist`, `gated`, or `checkout open`, and `checkout open` requires that the
product is finished and checked.

## 6. Lead magnet

Archetype and the awareness stage it meets. The one-outcome promise. Where it is sliced from.
Delivery path and time. Capture: two steps, the three questions. Baseline opt-in rate with
denominator and traffic source, or `[OPEN]`.

## 7. Packaging

Per product: shape, marketplace or rail, install or open path tested by whom and when, version,
policy checks done (acceptable use, fees, tax) with dates.

## 8. Launch sequence

Assets by awareness stage (identity and story → mechanism → offer and proof). The Dream 100
list: where buyers already gather, worked in before paid in. Daily volume commitment and run
length. The Hook, Story, Offer diagnostic owner.

## 9. Scoreboard

What is measured, how (command or source), cadence, owner. At minimum: members by label,
installs that run, would-pay by band, opt-in rate against own baseline, receipts delivered,
ritual kept. Then: what is not yet measured, stated plainly.

## 10. Open rulings

The decisions only the founder can take: prices, names, first publication, money rails,
external sends. One line each, with the recommendation and the evidence behind it.

---

## Field notes

- A brief that reads well but has empty "measured" fields is a plan, not a brief. Say so.
- If block 1 shows stage 4 or 5 and block 3 still offers an improvement, stop and rewrite
  block 3.
- If block 6's magnet serves a different buyer than block 2, pick one buyer.
- If block 5 shows a checkout on a rung with gate state `waitlist`, that is a defect.
- The brief is the artefact; the sales page, emails and product pages are built from it, not
  the other way round.
